# 🌌 Cyberpunk HUD

**A futuristic holographic system monitor for Capri Desktop.**

Cyberpunk HUD transforms your desktop experience with a sleek, futuristic holographic interface, featuring real-time hardware monitoring and a neon-inspired cyberpunk aesthetic.

## ✨ Features

- **CPU Monitoring** – Track real-time processor usage.
- **RAM Monitoring** – Monitor memory consumption.
- **GPU Monitoring** – Track NVIDIA GPU utilization.
- **GPU Temperature** – Keep an eye on your graphics card temperature.
- **Holographic Interface** – Futuristic visuals with a cyberpunk-inspired design.
- **Neon Aesthetics** – A customizable interface with glowing visual elements.

## 🎮 Commands

Control the HUD using natural voice commands:

| Command | Action |
|---|---|
| `initialize HUD` | Show / initialize the HUD |
| `remove HUD test` | Remove the HUD |
| `remove HUD` | Remove the HUD |
| `close HUD` | Close the HUD |
| `chiudi HUD` | Close the HUD |

## 📦 Installation

1. Download `cyberpunk-hud.capri-code`.
2. Open Capri Desktop.
3. Navigate to **CAPRI → Mods**.
4. Select **Import Mod**.
5. Choose the downloaded `.capri-code` file.
6. Enable the mod and authorize its execution.
